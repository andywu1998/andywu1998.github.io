# 域控芯片装机量排名图项目说明

## 项目目标

把用户提供的 NE时代域控芯片装机量榜单截图沉淀为一个可复用项目：保存结构化数据、生成脚本和图表成品。下次有新月份数据时，可以直接在同一项目里追加数据并重新生成图。

## 当前数据范围

- 2025年1-12月：单月榜单，已生成全年月度排名变化图。
- 2026年1-2月：两个月合计榜单。
- 2026年3月：单月榜单。
- 2026年4月：单月榜单，使用用户后续更正的 4 月原图。
- 2026年5月：单月榜单。
- 2026年6月：单月榜单。
- 2026年7月：单月榜单。
- 2026年8月：单月榜单，最新一期。

核心字段：

- 公司
- 装机量
- 市占率
- 当期排名

## 目录结构

- `scripts/domain_chip_data.js`：**唯一数据源**。`periods` 是各期榜单，`companies` 保存每家公司的颜色、各期装机量（`values`）和市占率（`shares`）。
- `data/domain_chip_source_data.csv`：从原图提取的标准源数据，包含装机量、市占率和排名。
- `data/domain_chip_2025_source_data.csv`：2025年1-12月从原图提取的标准源数据。
- `data/domain_chip_rank_table_chart_data.csv`：排名表格图使用的数据（由脚本生成）。
- `data/domain_chip_line_chart_data.csv`：折线图使用的数据（由脚本生成）。
- `scripts/generate_2025_rank_bump_chart.js`：生成 2025 全年月度排名连线图。
- `scripts/generate_rank_table_chart.js`：生成“排名表格图 + 公司连线”的主脚本。
- `scripts/generate_line_chart.js`：生成装机量趋势折线图。
- `outputs/domain_chip_rank_table_chart.svg` / `.png`：排名表格图的矢量版与位图版。
- `outputs/domain_chip_line_chart.svg` / `.png`：趋势折线图的矢量版与位图版。
- `outputs/domain_chip_2025_rank_bump_chart.svg` / `.png`：2025 全年月度排名连线图。
- `images/`：交付成图与原始截图的中文命名归档目录（`01`-`07` 为各期原图，`08`/`09` 为两张成图），成图内容与 `outputs/` 保持一致。
- `source_images/README.md`：原图归档说明。

## 当前最终图表

### 2025 全年月度图

2025 年 1-12 月数据采用“月份横轴 + 排名纵轴”的 bump chart：

- 横轴是 2025 年 1-12 月。
- 纵轴是每月排名 1-8。
- 每家公司固定一种颜色。
- 仅在连续上榜月份之间连线，缺席月份不强行连接。
- 每个点旁边显示公司、装机量和市占率。

当前输出文件：

```text
outputs/domain_chip_2025_rank_bump_chart.png
outputs/domain_chip_2025_rank_bump_chart.svg
```

### 2026 阶段图

每次交付两张图，都由 `scripts/domain_chip_data.js` 驱动：

**排名图**（`outputs/domain_chip_rank_table_chart.svg` / `.png`）：

- 每个时间段是一列表格，按装机量降序排列。
- 每家公司固定一种颜色。
- 公司在不同时间段之间用同色曲线连接，表现排名变化；缺榜期间不连线。
- 每行同时显示装机量和市占率。

**折线图**（`outputs/domain_chip_line_chart.svg` / `.png`）：

- 横轴是各期，纵轴是装机量。
- 每家公司一条同色折线，按连续上榜区间分段，缺月断开。
- 右侧是品牌图例。

## 复用步骤

下次用户提供新月份图片后：

1. 把新图保存到 `source_images/`，命名 `YYYY-MM_domain_chip_installation.jpg`（两个月合计用 `YYYY-01-02`）。
2. 打开图片读取榜单，把公司、装机量、市占率整理成一行行数据。
3. 编辑 `scripts/domain_chip_data.js`：
   - 在 `periods` 末尾追加新月份（注意顺序，不要跳月）。
   - 在每家公司的 `values` / `shares` 末尾追加当期数值；当期未上榜填 `null`。
   - 出现新公司时新增一行，并分配一个未使用过的颜色。
4. 在项目目录重新生成并渲染成图：

```bash
node scripts/generate_rank_table_chart.js
node scripts/generate_line_chart.js
rsvg-convert -w 2960 -h 1120 outputs/domain_chip_rank_table_chart.svg -o outputs/domain_chip_rank_table_chart.png
rsvg-convert -w 1700 -h 1000 outputs/domain_chip_line_chart.svg -o outputs/domain_chip_line_chart.png
```

说明：两个脚本会自动依据期数调整画布宽度（排名图每期 +480px，折线图按期数加宽），新增月份后不必手改尺寸；渲染宽度取整即可。

5. 把成图同步到 `images/`，并把文件名里的月份区间改成最新范围，例如
   `07_成图_2026年域控芯片装机量排名变化_1-2至8月.png`、
   `08_成图_2026年域控芯片装机量趋势_1-2至8月.png`。
6. 检查 PNG 排版后，用飞书机器人发送：

```bash
lark-cli im +messages-send --as bot --user-id ou_a0558e2fc4190751fee80e93d0895616 --image notes/projects/domain_chip_installation_rankings/outputs/domain_chip_rank_table_chart.png --format json
```

如果是追加 2025 或类似“全年月度图”，运行：

```bash
node scripts/generate_2025_rank_bump_chart.js
rsvg-convert -w 4600 -h 1480 outputs/domain_chip_2025_rank_bump_chart.svg -o outputs/domain_chip_2025_rank_bump_chart.png
```

## 本次注意事项

- 最初 4 月图片口径错误，已按用户更正后的 4 月图替换。
- 排名表格图原先在“公司相邻月份缺榜”时会画出跨期连线并产生 `NaN` 路径（德州仪器 7 月掉出前八、理想仅 7 月上榜）。现已改为：相邻两期都有排名才连线，且缺月不跨期硬连。
- 折线图同样按“连续上榜区间”分段绘制，缺月处断开，不跨月连假线。
- 2026 年 7 月新增原图已补入排名表格图、折线图和源数据；生成时 periods 需覆盖 1-2月/3月/4月/5月/6月/7月，避免跳过月份。
- 2026 年 8 月新增原图已补入：地平线升到第 2（161,063 颗 / 19.8%），特斯拉回到第 4，德州仪器重新上榜，理想掉出前八。德州仪器 7 月缺榜、8 月复榜，因此 6→7 月与 7→8 月都不连线，只保留 8 月单点。
- 当前环境无法直接复制对话图片附件到本地文件，因此本项目保存了结构化源数据，并在 `source_images/README.md` 记录原图来源和后续归档方式。
- 数据来源是用户提供截图，未额外做外部核验。

## 下一步动作
