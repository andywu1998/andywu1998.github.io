# 地平线 2025 年度产品发布会：修订总结

# 开场：地平线想做什么
余凯在开场把地平线定义为面向汽车和机器人时代的“计算平台”公司，也就是芯片加操作系统。他强调，地平线不只是要赚钱，更要成为推动科技文明进步的基础设施。

# 十年创业：从愿景到现实
地平线 2015 年创业时，最初的目标是把深度神经网络放进芯片，让车和设备具备感知、交互、决策与控制能力。过去十年里，公司经历过反复试错、战略收缩和聚焦，最终把重心压到智能驾驶和机器人计算平台上。

# 使命与价值观：安全优先，长期主义
余凯反复强调，安全是所有美好的前提。公司的价值观不只是写在墙上，而是要落实到长期选择里：耐得住寂寞、成就客户、避免短期投机、避开高风险边界。

# 战略方法：不在悬崖边跳舞
地平线的战略框架很简单：一是去没有竞争的地方竞争，二是不要在悬崖边跳舞。也就是说，选择有壁垒但不盲目的赛道，保持健康现金流，尽量避开高风险下注。

# 软硬结合：地平线的核心能力
地平线把自己定位成芯片、算法、车规、安全一体化的系统级公司。它既懂 AI 算法，也懂芯片设计，还懂量产和车规要求，这也是它和普通软件公司、普通芯片公司的关键区别。

# 用户痛点：智能驾驶还不够“像人”
发布会播放了大量用户反馈，核心抱怨集中在三个点：系统不够自然、复杂路况不稳定、驾驶风格不够成熟。用户真正需要的不是炫技，而是每天都愿意用、用起来安心的智能驾驶。

# L2、L3、L4：先把边界说清楚
余凯认为，很多 L3 讨论的问题在于 ODD 边界不清晰。更现实的路径是：先在清晰边界内做到接近 L4 的能力，再把边界外的大规模 L2 经验和数据积累起来，逐步走向更高阶自动驾驶。

# 征程 6P 与征程 6H：新一代算力芯片
发布会上最重要的硬件之一是征程 6P，旗舰算力约 560 TOPS，另外还推出了征程 6H。新一代芯片面向城区复杂辅助驾驶，重点强化了算力、存储结构和对 Transformer、Softmax 等计算的硬件优化。

# Horizon Cell：可插拔的车载计算平台
地平线还展示了可插拔式的车载计算机设计 Horizon Cell。这个思路像个人电脑升级硬件一样，让车企和用户在不同生命周期里都能获得更灵活的算力配置与升级路径。

# 安全与验证：量产数据才是底盘
地平线强调自己已有超过百万套辅助驾驶系统部署，积累了大量场景数据，并通过大规模道路验证和功能安全认证来证明系统可靠性。这里的重点不是宣传，而是把“能上路”建立在真实量产和验证之上。

# 结尾：把智能驾驶做成人人爱用的产品
这场发布会最后指向的不是单一芯片，而是一个完整产品闭环：芯片、算法、域控制器、HMI、量产验证和安全认证一起构成智能驾驶产品。地平线希望把它做成真正面向用户、每天都能用、而且更安全的产品。
