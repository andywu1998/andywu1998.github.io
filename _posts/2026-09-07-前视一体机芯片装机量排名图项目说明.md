# 前视一体机芯片装机量排名图项目说明

## 项目目标

把用户提供的 NE时代前视一体机芯片榜单截图沉淀为一个可复用项目：保存结构化数据、生成脚本和图表成品。下次有新月份数据时，可以直接在同一项目里追加数据并重新生成图。

## 当前数据范围

- 2026年1-2月：两个月合计榜单。
- 2026年3月：单月榜单。
- 2026年4月：单月榜单。
- 2026年5月：单月榜单。
- 2026年6月：单月榜单。
- 2026年7月：单月榜单。

核心字段：

- 公司
- 装机量
- 市占率
- 当期排名

## 目录结构

- `data/front_view_integrated_chip_source_data.csv`：从原图提取的标准源数据，包含装机量、市占率和排名。
- `data/front_view_integrated_chip_rank_table_chart_data.csv`：排名表格图使用的数据。
- `data/front_view_integrated_chip_line_chart_data.csv`：折线图使用的数据。
- `scripts/generate_rank_table_chart.js`：生成“排名表格图 + 公司连线”的主脚本。
- `scripts/generate_line_chart.js`：生成折线图的脚本。
- `outputs/front_view_integrated_chip_rank_table_chart.png`：当前最终交付图。
- `outputs/front_view_integrated_chip_rank_table_chart.svg`：当前最终交付图的矢量版。
- `outputs/front_view_integrated_chip_line_chart.png`：趋势折线图。
- `outputs/front_view_integrated_chip_line_chart.svg`：趋势折线图的矢量版。
- `source_images/README.md`：原图归档说明。

## 当前最终图表

### 2026 阶段图

最终采用“排名表格图 + 公司连线”的形式：

- 每个时间段是一列表格，按装机量降序排列。
- 每家公司固定一种颜色。
- 公司在不同时间段之间用同色曲线连接，表现排名变化。
- 每行同时显示装机量和市占率。

当前输出文件：

```text
outputs/front_view_integrated_chip_rank_table_chart.png
outputs/front_view_integrated_chip_rank_table_chart.svg
```

### 2026 趋势图

采用装机量趋势折线图：

- 横轴是 2026 年 1-2 月到 2026 年 7 月。
- 纵轴是装机量。
- 每家公司固定一种颜色。
- 标签保留关键数值，便于快速比较。

当前输出文件：

```text
outputs/front_view_integrated_chip_line_chart.png
outputs/front_view_integrated_chip_line_chart.svg
```

## 复用步骤

下次用户提供新月份图片后：

1. 将新图保存到 `source_images/`。
2. 从图中提取公司、装机量、市占率和排名，追加到 `data/front_view_integrated_chip_source_data.csv`。
3. 更新 `scripts/generate_rank_table_chart.js`：
   - 在 `periods` 中增加新月份。
   - 在 `data` 中为每家公司追加 `values` 和 `shares`。
   - 如果出现新公司，为该公司新增一行并分配颜色。
4. 在项目目录运行：

```bash
node scripts/generate_rank_table_chart.js
rsvg-convert -w 3320 -h 1120 outputs/front_view_integrated_chip_rank_table_chart.svg -o outputs/front_view_integrated_chip_rank_table_chart.png
```

如果要刷新趋势折线图：

```bash
node scripts/generate_line_chart.js
rsvg-convert -w 1900 -h 1000 outputs/front_view_integrated_chip_line_chart.svg -o outputs/front_view_integrated_chip_line_chart.png
```

## 本次注意事项

- 本项目与 `domain_chip_installation_rankings` 完全分离，文件夹、数据文件和输出文件都使用独立前缀。
- 数据来源是用户提供截图，未额外做外部核验。

## 下一步动作

- 新月份数据到来时，优先补齐 `source_images/` 原图文件，再追加结构化数据。
- 如果月份继续增加，图表宽度需要随列数扩展，或改为分页/横向长图。
